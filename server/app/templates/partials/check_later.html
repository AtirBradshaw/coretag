{# "Checking this item later?" - shown on report pages. Kept for later: the idea is that every report tells the next person how to compare a fresh run against it, either a buyer checking an item on arrival or a seller checking an item that came back (return fraud). The comparison engine behind it is fully built and tested; only this on-page prompt is switched off for now. To show it again, set the environment variable CORETAG_SHOW_CHECK_LATER=1 (in Render: the coretag service -> Environment), or change the default in server/app/main.py. #}

Checking this item later?

Bought it? When it arrives, run Coretag, choose "I just received this part" and enter code {{ rep.id }}.

Sold it and it came back? Run Coretag, choose "A part I sold came back" and enter the same code. Either way the server compares the new run with this one and publishes the result: same card, same condition?
