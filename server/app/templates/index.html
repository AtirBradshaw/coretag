Don't trust a screenshot. Read the card.

Coretag reads a graphics card's own sensors and firmware, puts it under five minutes of load, and publishes the measurements at a permanent link sellers can paste into any listing.

Have a Coretag code?

Works for report, comparison and part codes.

How it works

01 · SELLER

Test before listing

Run Coretag. It loads the card, records temperature, clocks and power, and the server scores the raw data.

02 · LISTING

Share the link

Paste the report link into eBay, r/hardwareswap, Marketplace or anywhere else. Include the code with the item.

03 · BUYER

Test on arrival

Run Coretag with the seller's code. The server compares both runs: same card? Same condition?

What Coretag can't see

  • Physical or cosmetic damage
  • Bent pins, corrosion, cracked PCBs
  • Power supply health
  • Coil whine
  • Remaining lifespan
